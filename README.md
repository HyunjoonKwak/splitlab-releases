# SplitLab 설치판 (베타)

차수별 분할매매 자동 프로그램 SplitLab의 Windows 설치 파일을 배포하는 곳입니다.
지금은 **초대받은 분만** 쓸 수 있는 베타이며, **모의투자 계좌 전용**입니다.

## 설치

1. 오른쪽 **Releases**에서 가장 위(최신) 항목을 엽니다.
2. **Assets**의 `SplitLab-Setup-<버전>.exe`를 받아 실행합니다.
3. "Windows의 PC 보호" 경고가 뜨면 **[추가 정보] → [실행]**. (서명 인증서를 아직 넣지 않아 나오는 경고입니다.)
4. 설치는 기본값 그대로 [다음]. 끝나면 창이 뜨고, 처음 한 번 **아이디·비밀번호(12자 이상)·초대 코드**를 넣어 계정을 만듭니다.
5. 이어서 본인 **모의투자 키**(키움 / 한국투자증권 모의)를 넣으면 자동매매가 켜집니다.

계정·키·거래 기록은 전부 **본인 PC 안에만** 저장됩니다. 운영자에게는 전송되지 않습니다.

## 업데이트

앱에 로그인하면 새 버전이 있을 때 화면 위에 안내가 뜹니다. **장이 열려 있지 않을 때** [업데이트]를 누르면 1~2분 뒤 새 버전으로 다시 열립니다. 업데이트 전 백업과 실패 시 자동 복구가 들어 있습니다.

## 자주 묻는 것

| 궁금한 것 | 답 |
|---|---|
| 창을 닫으면 매매가 멈추나요? | 아니요. X는 숨기기입니다. 멈추려면 트레이 아이콘 › **자동매매 멈추고 종료**. |
| 재부팅하면? | Windows **로그인 후** 자동으로 다시 켜집니다. 로그인 전에는 멈춰 있습니다. |
| 비밀번호를 잊었어요 | 트레이 아이콘 › **비밀번호 재설정**. 운영자도 비밀번호를 모릅니다. |
| 초대 코드가 안 돼요 | 코드는 한 PC에서 한 번만, 정해진 기간 안에만 쓸 수 있습니다. 운영자에게 새 코드를 요청하세요. |
| 문제가 생겼어요 | 트레이 아이콘 › **문제 신고 자료 저장** → 바탕화면 ZIP과 시각·화면 문구를 보내 주세요. 비밀번호·앱키·계좌번호는 보내지 마세요. |

## 주의
